# test_codespaces

A test repository for GitHub Codespaces setup and configuration.

## Getting Started with Codespaces

This repository is configured for GitHub Codespaces. To use it:

1. Click the green "Code" button on GitHub
2. Select the "Codespaces" tab
3. Click "Create codespace on main" (or your preferred branch)

The development environment will be automatically configured with:
- Git and GitHub CLI
- VS Code extensions (Copilot, GitLens)
- Basic development tools

## Local Development

You can also develop locally using VS Code with the Dev Containers extension installed. The same `.devcontainer` configuration will be used.
